# PlanMyTrip

AI-powered multi-agent travel planning platform.

## Tech Stack

- React + Vite + TypeScript
- Python + FastAPI
- LangGraph + LangChain
- PostgreSQL + pgvector
- Redis
- MCP
- Docker
- AWS

## Features

- AI travel planning
- Flight, train and bus discovery
- Hotel discovery
- Intelligent itinerary generation
- Budget optimization
- Multi-agent orchestration
- Human-approved booking
